## 5. 기술 스택 상세

| 구분 | 기술 | 버전 | 용도 |
|------|------|------|------|
| **Backend** | Java | 17 | 메인 언어 |
| | Spring Boot | 3.2.x | 프레임워크 |
| | Spring Security | 6 | 인증/인가 |
| | Spring Data JPA | 3.x | ORM |
| | WebFlux | 3.x | 비동기 HTTP |
| **Frontend** | Vue.js | 3 | UI 프레임워크 |
| | TypeScript | 5.x | 타입 안정성 |
| | Vuetify | 3 | UI 컴포넌트 |
| | Pinia | 2.x | 상태 관리 |
| | Vite | 5.x | 빌드 도구 |
| **Database** | MySQL | 8.0 | 메인 DB |
| | Redis | 7.2 | 캐싱/세션 |
| **Infra** | Docker | 24.x | 컨테이너 |
| | Nginx | 1.25 | 리버스 프록시 |
| | Let's Encrypt | - | SSL 인증서 |
| **External** | Upbit API | v1 | 거래소 연동 |
| | Groq API | - | AI 분석 |
| | Discord JDA | 5.0.0 | 봇 알림 |
